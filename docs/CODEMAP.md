# TIEFGANG A code map

Read the part you need; CLAUDE.md links here. Test scripts live outside the repo in /home/claude/pw (README lists each chunk's checks).

## src/core
display (integer scaler, bleed, safe area), lighting (room lamp: GLSL filter, palette SHADOW steps via LUT + Bayer dither; light.set, light.power), lockdown, haptics, audio (buses ui/machinery/bed/sensors/voices/music, mixer.duck), sfx (procedural foley; 3.6 drip, levels rebalanced (pw/loud36); SIG_RPM screw signatures steam4/steam3/diesel3/diesel4/turbine3; 3.1 page + book; 5.1 riffle), store (clearStoreNow), settings (plotAssist, decodeAssist, tableAssist, torpFailures, prompts), tween, typed, font (one 6 px face), pixels, palette, tool-icons (pencil, eraser, ruler, dividers, zoom, boat, left, right, book, close).

## src/controls
Data-driven kit: key (icon, latch, styles iron/brass/paper), lever, crank, hold (+cover; lift(rate) runs it up by motor, pressed, rising), switch, button+cover, drag; createControl(spec); hitPolicy (44 pt targets); persistent controls restore from saves; meter, tape, odometer.

- torpedo.ts (3.4): TORPEDOES (S steam 30/40/44 kn, E electric 30 kn), TorpSet, RUN (tube 30 m forward, reach 12, turn radius 95, arm 250), turnOut, TubeObs/TubesObs (obs.tubes every tick), eraOf, BOW_TUBES. - bridge.ts: BridgeObs (view, sights with opaque keys; Outline = ShipClassKey; marks), sense.ts (Signature, sigKey, BLIND, SoundObs, LookoutReport, Signal, NavObs, EnvObs), grid.ts (gridOf/Name/Rect/Centre, KR 55 5 = centre), cipher.ts (disc cipher, key sheet, MORSE), boat.ts, power.ts, TIME_SCALES.
