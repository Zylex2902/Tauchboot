# TIEFGANG A code map

Read the part you need; CLAUDE.md links here.

- src/core/: display (integer scaler, bleed, safe area), lighting (room lamp: GLSL filter over bleed+world, palette SHADOW steps via LUT + Bayer dither on the art grid; light.set({...}, ms); light.power() dims it with the battery), lockdown, haptics, audio (buses ui/machinery/bed/sensors/voices/music, mixer.duck), sfx (procedural foley), store (patrol storage), settings, tween, typed, font, pixels, palette
- src/controls/: data-driven kit (lever (knob grip|red), crank (style plain|spoked), hold (+cover), switch, button+cover, key, drag; createControl(spec)); hitPolicy (44 pt min targets); persistent controls restore(v) from saves; meter, tape, odometer displays
- src/obs/: observation layer + send(command); obs.hydro = beam on the trained bearing (voices: up to 6 sounds with gain/pan/rpm/sig/timbre/cav, rest = churn, hand = captain has the wheel); obs.calls + 'hydroCall' events (operator reports); sense.ts (Signature {engine steam|diesel|turbine, blades, shafts}, sigKey, BLIND arcs manual, SoundObs sources with opaque keys + own-noise level, LookoutReport, Signal, NavObs DR, EnvObs judged weather + thermometer); ships.ts (recognition manual, SCOPE_FOV/SURFACE), boat.ts (BOAT manual, BoatSet/BoatObs, TELEGRAPH, DIVE_DRILL), power.ts (POWER/ENDURANCE/RANGE/NOISE manual tables the sim is tested against, PowerObs, EngineSet), TIME_SCALES. The UI imports only this, never src/sim.
- src/sim/: core.ts (Sim: fixed 10 Hz tick, commands land on tick boundaries, effects + schedule as data, time compression with auto-drop on voice/alarm/phase, snapshot/load, lerped presentation), rng.ts (one-integer state), drill.ts (scope drill; lens height uses boat depth), boat.ts (tanks/air/planes/depth/pitch physics, crew depth keeping, test/crush depth), power.ts (diesels/motors, Peukert battery, charging, fuel, noise dB, rpm; engine crew routine or EngineSet by hand: clutch, charge, answer, start/stop req), dive.ts (dive drill), world.ts (true world, SimState.world, own rng stream; patrol area = 50 km BOX around the origin; newWorld(opts) plans a convoy route to pass the centre at a set time), fleet.ts (HULLS, convoys/escorts/independents: commodore guide keeps route + schedule, zigzag by day, frame turns together, ships steer to slots once a second, sea costs speed; tracks every 5 min), weather.ts (systems by season, wind/gust, sea builds + swell, fog/rain/squalls, visibility), sky.ts (sun/moon almanac, light 0..1), ocean.ts (mixed layer/thermocline, waterTemp, layerLoss), operator.ts (hydrophone operator, reads obs only: notices, classifies, calls new/second/many/class/drift/closing/turns/lost/deaf/clear with priorities and a 5 s gap, small news keeps time compression; sweeps the wheel when hydro.hand is false; state in SimState.hydro.op), sense.ts (obs layer's sim side, own rng: hydrophone SNR model + shared/own bearing error + fading + new key after 2 min lost, beam() feeds obs.hydro; lookouts by horizon/vis/light; command signals held until aerial up; DR without current; judged weather; lagging thermometer). SAVE_VERSION 7; v4-v6 saves migrate. Effect voice keep:true = no compression drop. Leaving a station (hull sends {type:'leave'}): control room hand -> crew keeps current depth; engine room hand -> crew keeps the answered speed as the order
- src/main.ts: boots sim from the save (or ?fresh / ?seed=), then the hull; autosave every 4 s, on drill phase and on hide/pagehide; ?debug loads src/debug/overlay.ts (truth vs observation, TRUTH tab / T key)
- src/hull/: hull.ts (travel, swipe, keys, uiState/restoreUi), strip, report slips, voice-pipe, pause, drill-card (both drills), time-plate, transit-art, boat-sound (vents/blow/pumps/creaks, diesels, motor whine from obs.boat.flow/power + hull events)
- src/stations/: station.ts (base; noSave, saveExtra/restoreExtra; useBoards/pin/pinControl/ctl, setSize lays boards out; panelRect), boards.ts (layout, Board frames, group, art, label), control-room (art-test layout: bow/stern planes boards, depth, tanks, orders; controls mirror obs.boat.set, crew drives them via Lever.set/Crank.drive/Hold.follow/setCover, byCode flag; telegraph answer pointer from obs.boat.answered), gauges (depth column, paper dials, roundDial, sight columns, bubble), radio-room (hydrophone: one loop set per voice from core/sfx sigSound(sigKey, timbre) at rate rpm/SIG_RPM, twin screws as two loops 1.3% apart, cav/selfNoise/churn/sea loops, lowpass by gain via LoopHandle.setTone; wheel mirrors obs.hydro.trained while the operator has it (noSave); enter sends hydroHand; operator calls typed onto the LOG pad), beat-recorder (visual twin: 3-band pen recorder, BufferImageSource scrolled 60 px/s), conning-tower + scope-view + ship-art (periscope), engine-room (telegraph repeater + answer lever + bell, diesels, battery, fuel, card; mirrors obs.boat.power.set), placeholders (data-driven grey boxes; chart table time lever wired), power-panel (engineer's card), panel-art
- Layout: 21 px header (name plate, voice tab, time plate); pause tab bottom-right. No stencil masks on frame-level layers. Bots find controls by position (pw/*.mjs helper A()).
- Test hook `?test`: window.__hull, __app, __mixer, __sim, __obs, __save; __noSave stops writes. Tests live in /home/claude/pw (drill.mjs, dive.mjs, save.mjs, timescale.mjs, hull.mjs, hits2.mjs, cr-controls.mjs / er-controls.mjs = every control drives the sim + animates + sounds; leave.mjs = leaving keeps depth and speed; serve.sh restarts the preview; power.mjs and engine.mjs run the sim headless in node via a rolldown bundle of pw/power-entry.ts; world.mjs via pw/world-entry.ts = convoy crossings, almanac, weather, layer; sense.mjs via pw/sense-entry.ts = sensor error/delay/dropout + fog checker; hydro23.mjs via pw/hydro23-entry.ts = signatures, two ships close together, deafness, arcs, operator calls, saves; twin.mjs = browser done-when (two voices, recorder, calls); sigaudio.mjs = signature buffers render and loop; truth.mjs = overlay screenshots); headless runs ~8 fps at 960x540 dpr 1, each CDP touch ~300 ms.
